# 프로젝트 목적

이 프로젝트는 네이버 실제 데이터를 활용한 블로그 키워드 추천 시스템입니다.

## 최초 1회 설정

- `.env.example`을 복사하여 `.env` 파일을 생성합니다.
- 사용자는 아래 API 값 5개를 직접 입력합니다.

```text
NAVER_CLIENT_ID
NAVER_CLIENT_SECRET
NAVER_AD_API_KEY
NAVER_AD_SECRET_KEY
NAVER_AD_CUSTOMER_ID
```

- 사용자는 자신의 블로그 분야를 최초 1회 입력합니다.

예시:

```text
내 블로그 분야는 건강·의학이야. 저장해줘.
```

Codex는 분야를 `config.json`에 저장하며 이후 실행에서 다시 묻지 않습니다.

## 이후 사용 방법

사용자는 아래 명령만 사용합니다.

1.

```text
오늘 키워드 알려줘.
```

2.

```text
오늘은 1번 키워드로 할게.
```

또는

```text
오늘은 OO 키워드로 할게.
```

날짜가 지정된 요청은 해당 날짜를 사용합니다. 예: `2026년 8월 4일 키워드 알려줘.`

## Codex 동작 규칙

- 사용자가 Python이나 PowerShell을 직접 실행하도록 안내하지 않습니다.
- 사용자가 CSV를 직접 수정하도록 안내하지 않습니다.
- 필요한 파일 수정과 실행은 Codex가 대신 수행합니다.
- 추천 결과는 엑셀(`.xlsx`) 파일과 원본 CSV를 생성합니다.
- 정상 분석된 키워드를 점수순으로 최대 30개 저장하고 상위 3개를 강조합니다.
- 정상 분석 결과가 30개 미만이면 `TOP30을 만들기 위한 정상 데이터가 부족합니다`라고 표시합니다.
- 번호 선택은 가장 최근 TOP30 결과의 순위를 사용합니다.
- 키워드명 선택은 가장 최근 TOP30에서 공백 제거 후 정확히 일치하는 항목만 사용합니다.
- 선택한 키워드는 선택일부터 14일 동안 추천에서 제외합니다.
- API 키와 Secret Key를 코드, 로그, 채팅 결과에 출력하지 않습니다.
- OpenAI API와 `OPENAI_API_KEY`를 요구하거나 사용하지 않습니다.
